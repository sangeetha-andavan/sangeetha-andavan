# Sangeetha Andavan

**Radio astronomy · Interferometry · Instrumentation · Signal processing**

I am a Project Assistant at IIT Indore working on radio astronomy instrumentation, interferometric observations, SDR signal processing, and scientific Python tools. I am interested in PhD research combining observational radio astronomy with the instruments and analysis methods used to study astronomical sources.

## Projects

- **[Instructional Radio Interferometer](https://github.com/sangeetha-andavan/instructional-radio-interferometer)** — Low-cost 21-cm interferometer, SDR synchronisation, GNU Radio correlation, calibration, and solar observations.
- **[Spectrum Analyzer Python Tools](https://github.com/sangeetha-andavan/spectrum-analyzer-python-tools)** — Python tools for RF spectrum acquisition, CSV export, comparison, and plotting.
- **[CASPER Toolflow Setup](https://github.com/sangeetha-andavan/casper-toolflow-setup)** — Installation and troubleshooting notes for the CASPER toolflow and ZCU216 RFSoC.
- **[Radio Astronomy Literature Toolkit](https://github.com/sangeetha-andavan/radio-astronomy-literature-toolkit)** — Python notebooks for calculations and visualisations based on radio astronomy literature (currently private).

## Research interests

- Radio interferometry and visibility analysis
- Observational radio astronomy and 21-cm spectral-line studies
- Radio instrumentation and RF measurements
